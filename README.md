# MYKOT 대학생 로컬버디 모집 랜딩페이지

GitHub Pages 배포용 정적 웹페이지입니다.

## 배포 방법
1. GitHub에서 새 저장소를 만듭니다. 예: `mykot-local-buddy`
2. 이 폴더의 `index.html`, `.nojekyll`, `README.md`를 저장소 최상위에 업로드합니다.
3. 저장소의 `Settings` → `Pages`로 이동합니다.
4. `Build and deployment`에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`를 선택하고 저장합니다.
6. 잠시 후 `https://사용자명.github.io/mykot-local-buddy/` 주소로 공개됩니다.

## 참고
- 이메일 지원 버튼은 `mailto:` 링크를 사용합니다.
- 외부 폰트는 Google Fonts와 jsDelivr에서 불러옵니다.
- 카카오톡/SNS 공유 썸네일을 사용하려면 공개 이미지 URL을 준비한 뒤 `og:image` 메타 태그를 추가하세요.
